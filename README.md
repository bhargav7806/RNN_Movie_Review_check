🎬 RNN Movie Review Sentiment Analysis (Streamlit App)
📌 Project Overview

This project is a Sentiment Analysis Web Application built using:

Recurrent Neural Network (RNN)

Natural Language Processing (NLP)

Streamlit (for deployment)

The model predicts whether a movie review is:

✅ Positive

❌ Negative

based on the text entered by the user.

🚀 Features

Clean and interactive web interface using Streamlit

Real-time sentiment prediction

Text preprocessing and tokenization

Trained RNN deep learning model

User-friendly input box for review testing

🧠 Model Architecture

Embedding Layer

Simple RNN Layer

Dense Output Layer (Sigmoid activation)

Loss Function: Binary Crossentropy
Optimizer: Adam
